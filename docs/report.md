## Средняя сложность

- **№8 Перевернуть строку** — `lab2/reverse.py`: строки в Python
  неизменяемы, поэтому символы копируются в результат по одному
  в обратном порядке.
- **№10 Словарь квадратов** — `lab2/squares.py`: цикл `for` по
  `range(1, limit + 1)` заполняет словарь парами `число: квадрат`.
- **№4 НОД двух чисел** — `lab2/gcd.py`: перебор делителей от 1 до
  минимума из двух чисел, значения приводятся через `abs()`.

## Повышенная сложность

- **№8 Бинарный поиск** — `lab2/searching.py`: классический
  алгоритм с двумя индексами `low`/`high` и серединой отрезка,
  возвращает индекс или `-1`.
- **№1 Сортировка пузырьком** — `lab2/sorting.py`: соседние
  элементы переставляются местами, внешний цикл останавливается
  досрочно, если проход прошёл без обменов; на вход копируется
  список, исходный не меняется.

## Проверка

- Демонстрация: `python -m lab2`.
- Тесты: `python -m unittest discover -s tests -v`.
- Стиль: `flake8 lab2 tests` (max-line-length = 79).
